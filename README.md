# 即時通客製化模板

一個單一檔案的網頁工具：調整名稱、顏色、圓角、陰影、字體與明暗，即時預覽屬於自己的即時通介面。

不需要安裝、不需要登入，也沒有後端；所有設定只存在使用者自己的瀏覽器與網址裡。

## 使用方式

打開網頁後：

1. 從「原版、柔和、報紙、手寫、夜貓」挑一個範本開始，或直接自己調。
2. 改名稱、主色、標記色（可用「自訂」選任意顏色）、圓角、陰影、字體、明暗。
3. 按「複製分享連結」，把連結傳給別人，對方打開就會看到同一組設定。
4. 需要留存時按「下載設定檔」，會得到一個 JSON 檔。

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的公開版本庫（repository）。
2. 把這個資料夾裡的 `index.html`、`README.md`、`.nojekyll` 上傳到版本庫的最上層。
3. 進入版本庫的 Settings → Pages，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，頁面上方會出現網址，格式是 `https://<你的帳號>.github.io/<版本庫名稱>/`。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個工具，樣式與程式都在這一個檔案裡 |
| `.nojekyll` | 告訴 GitHub Pages 直接提供檔案，不做額外處理 |
| `README.md` | 這份說明 |

## 注意事項

- 字體從 Google Fonts 載入，離線時會退回裝置內建字體。
- 這個工具產出的是介面外觀設定，不包含收發訊息的功能。
